Before you start

開始之前

三件事，5 分鐘搞掂。

A

開帳戶

去 claude.ai 用 Email 或 Google 帳戶登入，亦可以喺手機下載 Claude App。免費版已經夠你完成成本手冊嘅練習。

B

認識介面

  • 新對話：每個新題目開一個新對話，Claude 會專心啲
  • 左邊側欄：以前嘅對話、Projects 都喺度
  • ＋ 號 / 迴紋針：上傳相片、PDF、Word、Excel 俾 Claude 睇
  • 設定：可以寫低你嘅個人偏好，等 Claude 每次都記得
小提示：介面間中會更新，按鈕位置未必一模一樣，搵唔到就直接問 Claude「喺邊度可以設定 XXX？」
C

記住三條底線

  • 唔好貼密碼、身份證號碼、信用卡、客戶私隱資料
  • 數字、日期、法律 / 醫療資料，一定要自己再核對
  • Claude 係你嘅助手，最後判斷同責任喺你度
Step 0 · 入口

先跑呢條 Prompt，
等 Claude 幫你度身訂造

填入你嘅職業，貼入 Claude。佢會話你知每個功能喺你份工入面可以點用——之後學每一步都會更有感覺。

PROMPT 00 · 度身訂造學習路線
你係一位有耐性嘅 Claude 入門導師，學生係完全冇用過 AI 工具嘅新手。 我嘅職業 / 工作內容係：[例如：小店老闆、行政文員、補習老師、IG 創作者] 我最想慳時間嘅工作係：[例如：回覆客人訊息、寫宣傳文案、整理會議紀錄] 請用廣東話，由淺入深介紹以下 Claude 功能： 1. 基本對話（點樣問問題） 2. Projects（專案） 3. 記憶 / 個人偏好設定 4. Artifacts（直接整成品） 5. Skills、Connectors 等進階功能（簡單帶過就得） 每個功能請包括： - 一句話講清楚佢係咩 - 2 個同我職業直接相關嘅用法 - 1 個「今日 10 分鐘內就試到」嘅小任務 唔好用術語，例子要具體、貼近香港日常工作。
Basics · 1–5

入門五步：
由問對問題，到整出成品

跟次序做，每步大約 10–30 分鐘。

01

問對問題：四格公式

答案質素 = 問題質素。「幫我寫篇文」同「以 XX 身份，為 XX 讀者寫一篇 XX 字、XX 語氣嘅文」係兩個世界。

角色你想佢扮邊個
任務具體要做咩
背景對象、情況
格式長度、樣式
PROMPT 01 · 四格公式範本
【角色】你係一位 [例如：有 10 年經驗嘅社交媒體編輯]。 【任務】幫我 [例如：寫 3 個 IG 帖文開場句，宣傳週末手作班]。 【背景】 - 對象：[例如：25–40 歲、鍾意手作嘅上班族] - 已知資料：[例如：逢星期六下午，$380 一位，材料全包] 【格式】 - 每個開場句唔超過 25 字 - 語氣輕鬆，用廣東話 - 唔好用問句開頭
02

追問，唔好收貨太早

第一個答案通常只係草稿。直接話俾 Claude 知邊度唔啱、要改咩——佢會記得同一個對話入面嘅內容，唔使重新講過。

常用追問：「再短啲」「講得具體啲」「揀第 2 個展開」「用小學生都明嘅方式再講一次」「你仲需要咩資料先答得好啲？」
PROMPT 02 · 追問模板
第 [N] 個版本最接近我想要，但係 [例如：太長 / 太正式 / 唔夠具體]。 請： 1. 保留佢嘅 [例如：開頭嗰句] 2. 改成 [例如：一半長度、更口語] 3. 另外俾多 2 個唔同方向嘅版本俾我揀 改之前，先用一句話講你會點改。
03

用 Projects 開一個專屬工作室

每次都要重新解釋背景好煩？開一個 Project，將相關文件同指示放入去，喺呢個 Project 入面開嘅對話，Claude 都會參考返呢啲資料。

  • 點開：左邊側欄 → Projects → 新增
  • 放咩入去：品牌介紹、產品價錢表、你寫得最好嘅 3–5 篇範文
  • 建議分類：一個工作範疇一個 Project（例如「IG 內容」「客人查詢」「課程準備」）
PROMPT 03 · 貼入 Project 指示（Instructions）
你係 [品牌 / 公司名] 嘅內容助手。 關於我哋： - 做咩：[一句話] - 客人係：[一句話] - 語氣：[例如：親切、直接、用廣東話，唔好太多 emoji] - 避免：[例如：誇張字眼、「史上最」之類嘅說法] 工作方式： 1. 我叫你寫嘢時，如果資料唔夠，先問我最多 3 條問題 2. 參考 Project 入面嘅文件，唔好自己作資料 3. 改我嘅草稿時，先列出改咗邊度、點解，再俾修改版
04

等 Claude 記得你係邊個

喺 設定 入面可以填寫個人偏好（例如你嘅職業、想佢用咩語言同語氣），之後每個對話都會套用。部分方案仲有「記憶」功能，會記住你以前傾過嘅重點。

唔知點寫？用下面條 Prompt，等 Claude 訪問你，再幫你整理成一段自我介紹。

PROMPT 04 · 整理你嘅「Claude 說明書」
我想寫一段個人介紹，放入 Claude 嘅個人偏好設定，等你以後每次都了解我。 請你逐條問我問題（一次問一條，等我答完先問下一條），包括： - 我嘅職業同日常工作 - 我最常叫你幫手做嘅 3 件事 - 我鍾意嘅回覆語言、語氣同長度 - 我唔鍾意嘅寫法 問完之後，幫我整理成一段 150 字以內嘅個人介紹，用第一人稱，方便我直接複製貼上。
05

用 Artifacts 直接整成品

Claude 唔止俾建議，仲可以直接整出可以用嘅嘢：網頁、互動小工具、表格、文件、圖表。成品會喺對話旁邊顯示，可以即時預覽、下載或者分享。

關鍵字：喺 Prompt 講明「整一個可以直接用嘅 ___」，例如「整一個互動網頁」「整一個表格」。
PROMPT 05 · 第一個 Artifact
幫我整一個可以直接用嘅互動網頁：[例如：一週內容計劃表]。 內容： - 星期一至日，每日一格 - 每格可以填：主題、平台（IG / Threads / Facebook）、狀態（構思中 / 製作中 / 已發佈） - 預先填好 7 個關於 [你嘅範疇] 嘅主題建議，我之後再改 設計： - 簡潔、手機睇都清楚 - 主色：[例如：米白 + 深灰 + 一個亮色] - 介面文字用繁體中文
Advanced · 6–10

打好底之後：進階地圖

熟咗頭五步先玩呢啲。部分功能要付費方案或者電腦版 App，而且會不斷更新，以 Claude 官方說明為準。

06 · Skills

自訂技能

將你成日重複嘅做法（例如寫帖文嘅格式）教識 Claude 一次，之後一句指令就照做。

07 · Connectors

連接外部工具

連上 Google Drive、Gmail、Notion、Calendar 等，Claude 可以讀真實資料、幫你執行動作。

08 · Scheduled Tasks

自動排程

設定固定時間自動做嘢，例如每朝整理行程、每週一出一份選題建議。

09 · Plugins

工作流打包

將 Skills 同 Connectors 打包成一套，方便自己用，亦可以分享俾團隊或學員。

10 · Cowork

幫你操作電腦

喺電腦版 App 直接讀取、整理、建立你電腦上嘅檔案，例如執資料夾、批量改檔名。

11 · Dispatch

手機遙距指揮

喺手機發指示，叫電腦上嘅 Claude 幫你做嘢，搭車、等人都推進到工作。

留意：用 Connectors、Cowork 呢類可以「做嘢」嘅功能時，叫 Claude 先列出計劃俾你確認先執行；涉及刪除檔案、寄電郵、付款等操作，一定要自己睇清楚先批准。
Common mistakes

新手最常犯嘅 5 個錯

✕

問得太短——「寫篇文」冇對象、冇長度、冇語氣，出嚟一定好泛。用返四格公式。

✕

一個對話傾晒所有嘢——題目轉咗就開新對話，唔係 Claude 會混淆之前嘅內容。

✕

第一個答案就收貨——追問兩三次，質素通常會明顯好好多。

✕

盡信所有資料——Claude 都會講錯，尤其係數字、日期、最新消息同引用來源。

✕

一開始就衝去玩進階功能——冇打好 Projects 同個人偏好嘅底，進階功能都唔會好用。
